JUNGLE KING · 山河獸影
Experimental real-time capture integration

This is a generated playable distribution. Open index.html directly in a browser,
or run python3 launch.py. Do not open the HTML in a text/source preview.
Keep battle.html beside index.html. The elephant model is embedded; Three.js and
Rapier still require internet. Try 「試玩 3D 巨象捕獲」, then elephant D5 → tiger D6.
Only elephant-attacking-tiger uses real-time 3D; other captures remain painted.
P pauses; Space/Esc skips. Skipping resolves the legal move exactly once.
The source repository includes editable code/media, tests and build instructions.
Credits and licenses are preserved. No website is deployed by opening this file.
