# Jungle King · 鬥獸棋

Play animal chess against the computer on a painted landscape board, with
animated captures, music and sound effects. The game interface is in
Traditional Chinese.

## Start playing

Open `index.html` from the playable distribution in a browser with JavaScript
and Canvas support, such as Chrome, Edge, Firefox or Safari. Open the file in
the browser itself; a file or source preview may not run the game.
The painted game works offline once downloaded.

If you have the source repository rather than a playable distribution, see
[DEVELOPMENT.md](DEVELOPMENT.md) to build it first.

1. Choose 「入局對弈」 to start a game against the computer.
2. Select one of your blue animals, then select a highlighted square to move or capture.
3. Enter the opponent’s den to win. Choose 「棋規」 for the full rules or
   「學習棋規」 for interactive practice.

Choose 「試玩巨象撼虎」 or 「試玩獅豹對決」 to try a capture scene.

## Controls and settings

- Drag to rotate the board; use the mouse wheel to zoom.
- Use the arrow keys and Enter to select a square; Esc cancels selection.
- During a capture animation, press P to pause or Space to skip.
- Use 「提示」 for a hint and 「悔棋」 to undo the last round.
- Adjust difficulty, music, sound effects and reduced motion in the game controls.
- Choose 「續上局」 when available to resume a saved game in the same browser.
